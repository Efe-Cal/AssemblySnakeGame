# Assembly Snake
A simple snake game written almost entirely in x86 GNU Assembly.

## Description
A simple snake game that runs in the terminal. Controls are the WASD keys. Don't hit the walls, but you can go through yourself! Collect the apples, the letter A, to grow your snake. The game ends when you hit the wall.  
The game is written in x86 GNU Assembly but it calls some C functions to handle the terminal.

## Getting Started

### Dependencies
- Linux or WSL

### Installing and Running
- Download the executable file from the releases page or compile it yourself using `make`.
- Run the executable file in your terminal: `./snake`
